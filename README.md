# 千问 · 桌面助手

面向 PC 浏览器的本地聊天应用。接入千问 API，支持流式输出、停止与打断、工具卡片、语音输入与朗读、图片理解、文档问答、联网搜索，以及账号和服务端会话同步。

2026-09-30 用户已授权再迭代两轮后制作 Windows 桌面安装包，当前正在按顺序推进。

当前为 `v0.11.0`：在多模态、联网与本地账号同步基础上，修复中文输入法切换会话后的发送失效，以及满草稿下语音转写结果的恢复。132 项核心测试与 42 项浏览器场景通过。尚未部署公网服务。版本验证、差距和截图见 [迭代记录](docs/iterations.md)。

## 本地运行

准备 **Node.js 24+**（账号服务使用内建 SQLite），并确保启动终端能读取系统环境变量 `Qianwen_api_key`。配置变量后需要重新打开终端。密钥仅在本地后端读取。

```powershell
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 。开发服务器和后端分别使用 5173、3001 端口，均在本机运行。

可选系统环境变量：

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `QWEN_MODEL` | `qwen-plus` | 使用的千问模型 |
| `QWEN_BASE_URL` | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 与 API Key 地域匹配的兼容接口地址 |
| `QWEN_VISION_MODEL` | `qwen3-vl-plus` | 图片理解模型，有图片的上下文自动选择 |
| `QWEN_ASR_MODEL` | `qwen3-asr-flash` | 录音转文字 |
| `QWEN_TTS_MODEL` | `qwen3-tts-flash` | 回复语音合成 |
| `QWEN_TTS_VOICE` | `Cherry` | 合成音色，须为所选模型支持的音色 |
| `QWEN_DASHSCOPE_BASE_URL` | 由兼容接口域名推导 `/api/v1` | 联网与语音合成使用的原生接口 |
| `QWEN_DATA_DIR` | 项目 `.local/` | SQLite 账号、同步副本及附件持久化目录 |

现有 Key 同时用于这些模型；需要对应地域的模型权限和可用额度。图片、语音、联网会产生相应模型调用费用，文档在本地解析后将提取文字随问答发送给千问。默认地址适用于北京地域；其他地域须同时确认接口地址和模型可用性，见 [官方地域说明](https://help.aliyun.com/zh/model-studio/regions)。

`.env.example` 仅是配置说明，应用直接读取系统环境变量。请勿将密钥填入前端代码、聊天输入框或提交到 Git。

构建后运行：

```powershell
npm run build
npm start
```

打开 http://127.0.0.1:3001 。本地服务会提供构建后的网页与 API。调用千问需要网络和有效的账户额度。

Windows 下可用 `npm run start:background` 在后台启动构建版本，用 `npm run stop:background` 停止它。后台日志保存在 `.local/`。切回 `npm run dev` 或运行浏览器测试前，先停止占用 3001 端口的构建服务。

## 面试演示

1. **流式对话**：发送“用三个生活中的例子解释什么是流式输出”，观察回复逐步出现。
2. **打断**：要求生成较长内容，途中点击停止；保留已有内容，再发送新的问题。
3. **计算器**：开启工具，发送“请调用计算器计算 (128 * 35 + 256) / 12”，展开工具参数并复制结果。
4. **资料检索**：发送“检索本地资料中关于流式输出和打断的内容”，展开命中的原文，再选择条目追问。
5. **会话恢复**：新建并切换会话，刷新页面，检查已保存的消息和工具卡片。
6. **图片和文档**：点击“添加附件”或拖入文件；可先展开文档摘要，再提问。图片交给视觉模型，文档提取正文随上下文发送。
7. **语音**：允许麦克风，录音后可试听、取消或转成文字。确认文字后发送；回复旁点击朗读，可随时停止。
8. **联网搜索**：打开输入区的联网开关，询问近期信息；回答下方可展开真实网页来源并访问链接。
9. **账号同步**：侧栏注册账号，创建会话并预览上传；用另一个浏览器或无痕窗口登录同一账号，预览下载并选择合并或替换。两个窗口同时修改时，旧版本上传会被拒绝，需要刷新预览。

工具执行真实计算与本地检索。本地资料是仓库自带的演示资料；联网开关独立使用阿里云原生检索，并渲染其返回的网页来源。工具由模型选择调用；是否调用会受模型和问题影响。

PC 操作：Ctrl/⌘+K 新建对话，Ctrl+/ 聚焦输入框，Esc 停止生成（有弹窗时先关闭弹窗）。侧栏可搜索历史标题及消息内容；代码块支持单独复制。

侧栏“本地备份”可以导出当前内存中的全部会话、消息和草稿。导入 JSON 时先预览，再确认追加；不会覆盖原会话或重新执行工具。文件上限 10 MB，导入后合计最多 50 个会话，每个导入会话保留最近完整回合、最多 100 条消息；预览明确列出裁剪数量。格式、恢复容量或浏览器写入检查失败时不导入。备份文件包含聊天内容，请按自己的需要保存。

资料卡片默认展示摘要和来源。点击“基于这份资料追问”会在输入区附上可移除的引用，你可以直接编辑自己的问题；原文和来源会随请求交给模型，并保存在对应的用户消息中。

## 附件、语音和同步规则

| 功能 | 当前规则 |
| --- | --- |
| 图片 | PNG、JPEG、WebP；每张最多 5 MiB、2500 万像素；每条消息最多 4 个附件，模型上下文保留最近最多 4 张图片 |
| 文档 | UTF-8 TXT / Markdown、文字版 PDF、DOCX；每份最多 10 MiB，提取前 8000 字，截断有提示；扫描 PDF 请改为上传图片 |
| 附件存储 | 账号或访客分别隔离；每个身份最多 200 个附件、200 MiB，原文件保存在服务端 |
| 语音 | 浏览器录音最长 60 秒、最多 6 MiB；录完转写后可编辑；朗读分段合成，可停止，切换会话会停止播放 |
| 同步 | 手动预览上传/下载，最多 50 个会话、每个 100 条消息、6 MiB 请求；版本冲突阻止覆盖 |

账户密码采用加盐 scrypt 散列，登录使用 7 天 HttpOnly 会话 Cookie。访客和各账号的浏览器缓存分别保存；登录不会自动上传访客聊天，退出恢复访客空间。同步包含会话、草稿、工具结果、附件引用和搜索来源。附件属于上传时的身份，同一账号连接同一服务可继续读取；跨账号或迁移到另一服务的 JSON 备份不会搬运文件，需要重新上传。

移除附件卡片或删除会话只修改会话引用，不删除服务端原文件。当前通过数据目录管理文件，尚无附件回收界面。账号服务暂不提供找回密码、自动后台同步或账号删除。

## 后续云部署

本地验证无需另配认证服务或数据库。`.local/accounts.sqlite` 保存账号和同步副本，`.local/uploads/` 保存附件，均已排除 Git。迁移或备份时先停止服务，再一起复制整个数据目录；如果数据库在运行，需使用 SQLite 一致性备份而不是单独拷贝主数据库文件。

真正跨设备使用时，需要把同一应用和持久化数据目录放到可达服务器，并配置域名、HTTPS 和反向代理：设置 `QWEN_PUBLIC_ORIGIN=https://你的域名`，根据代理位置设置 `QWEN_HOST`（默认只监听 `127.0.0.1`）；仅在恰好一层可信代理后设置 `QWEN_TRUST_PROXY=1`。代理必须支持长连接，关闭 SSE 缓冲，并允许附件上传。公网模式启用 Secure Cookie，模型和附件接口要求登录。服务器仍需配置相同地域的模型 Key；当前仓库未执行云部署。

## 实现结构

- `src/`：React 界面、会话状态、SSE 客户端、Markdown 和工具组件。
- `server/`：Express API、千问流式适配、工具、隔离的文档解析、附件存储、SQLite 账号和同步。
- `shared/`：前后端事件合同及跨数据块 SSE 解码器。
- `data/knowledge/`：随项目提供的本地演示资料。
- `tests/`：核心协议与后端测试，以及浏览器交互测试。
- [项目约定](AGENT.md)、[千问 App 对照依据](docs/qianwen-reference.md)、[迭代记录](docs/iterations.md)。

浏览器以 POST 提交本轮消息，后端通过 SSE 返回带 `runId`、`conversationId`、`messageId` 的文本增量和工具事件。取消信号沿请求链传播，前端同时按请求标识隔离迟到事件。

工具调用参数完整后才校验和执行；结果通过对应调用 ID 回传给千问，继续生成回答。用于显示的历史记录与模型协议消息分开处理，避免打断后遗留没有结果的工具调用。

## 验证命令

```powershell
npm run check
npm run test:e2e
```

端到端测试默认使用已安装的 Google Chrome。核心测试使用受控响应验证边界，不消耗模型额度；真实 API 的验证情况与截图见迭代记录。

本地服务运行后，可执行 `npm run test:live` 重现真实流式、计算器、资料检索和中途取消检查。该命令会调用千问并消耗账户额度，简短结果写入不会提交的 `.local/live-check.json`。

`npm run test:live:features` 检查实际图片理解、TXT/PDF/DOCX 问答、联网来源与计算器组合、语音合成再转写；同样消耗模型额度，结果写入 `.local/live-features.json`。浏览器自动测试使用虚拟麦克风验证录音与取消流程，真实设备的收音和音量请在验收时体验。

## 当前范围

支持文本与图片/文档问答、录音转写与回复朗读、深度思考、计算器、本地资料检索、联网搜索、本地备份和账号手动同步。浏览器保存当前及最近 50 个会话、每会话最多 100 条消息；只有显式上传的账号副本才保存在服务端。模型请求会按完整回合裁剪近期上下文。语音采用录音后转写，不是实时通话；文档解析不包含扫描件 OCR、表格工作簿或 PPT。

开发地址（5173）和构建地址（3001）是不同站点，浏览器历史彼此独立；可通过本地备份导出、导入转移。验收建议使用构建地址 3001。

此项目参考千问官方公开的产品信息改进交互，属于独立面试演示项目。对照不等于安装并登录手机 App 的实机测试。
